# The OG Elo

The OG Elo is a simple beginner-friendly web project built to understand how real AI-style websites work.

It looks like an AI, acts like an AI, but answers with pure mood swings.

This project was made to learn:
- how frontend and backend talk to each other
- how Python can power a website
- how to structure a real project
- how to use GitHub properly

---

## What it does

- User types any question
- Backend randomly picks a response
- The response is intentionally unserious and moody
- UI reacts with animations and visual effects

No real AI logic yet — this is about **architecture, not intelligence**.

---

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Version Control: Git & GitHub

---

## Features

- Night pink themed UI  
- Random shuffled responses (100+ answers)
- Crying emoji animation on every question
- Black & white styled answer box
- Lightweight and fast
- Beginner friendly codebase
